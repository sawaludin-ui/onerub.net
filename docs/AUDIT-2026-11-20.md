# Audit rilis ONERUB.NET

20 November 2026, WIB · BNB Smart Chain, jaringan 56

## Tampilan dan interaksi

Logo situs dan favicon memakai PNG lampiran asli. SHA-256 berkasnya `2ec6fe89272565f42e567bab2b920231142a7540d9fd5b5aa251e87a9af21a57`. Komposisi halaman mengikuti Dayos dengan judul empat baris, navigasi kapsul, tombol hitam dan objek tiga dimensi. Judul menggunakan Barlow Condensed Bold. [Acuan Dayos](https://styles.refero.design/style/ee403055-480e-4bd4-9216-07c9ae2dde2e)

Objek dibuat dari bentuk logo, dirender menjadi animasi enam detik, lalu disajikan sebagai WebM atau MP4. Poster WebP berukuran 86.098 byte. Pengunjung dapat menjeda animasi. Preferensi kurangi gerakan dan hemat data memilih poster saat halaman dibuka. Pemutaran berhenti ketika objek keluar dari layar atau tab disembunyikan. Menu dan dialog tugas mendukung papan ketik dan pengembalian fokus.

## Aturan kantor dan backend

| Pemeriksaan | Hasil |
| --- | --- |
| Tugas | Bank 5.000 dataset. Lima pilihan per jenjang per hari WIB. Kontrak membatasi setiap karyawan ke satu tugas utama per hari. |
| Review dan lencana | Reviewer memutuskan benar atau salah. Karyawan dapat mencetak satu lencana untuk pekerjaan yang diterima. Bantuan untuk junior tidak menambah kredit tugas utama. |
| Transaksi | Server menyiapkan data tanpa tanda tangan untuk kontrak kantor di jaringan 56 dengan nilai transfer nol. Sebelum mengirim, antarmuka memeriksa kembali jaringan dan akun aktif. |
| Masukan API | Jenis konten, ukuran data, alamat, ID, keputusan reviewer dan batas teks diperiksa sebelum pemrosesan. Batas teks dihitung dalam byte UTF-8 seperti pada kontrak. |
| Direktori | Pembacaan menggunakan blok yang konsisten. Pengujian dengan 131 karyawan contoh memeriksa kelengkapan dua halaman dan batas enam pembacaan anggota sekaligus. Data per dompet memakai `no-store`. |
| Browser | Halaman mendapat nonce CSP baru per respons. Skrip produksi dibatasi asalnya. Penyematan dalam frame dan pemuatan objek diblokir. |

## Bukti pengujian

Instalasi bersih dan build produksi berhasil. Dua puluh tes otomatis lulus dalam lima putaran berturut-turut. Cakupan mencakup pergantian hari WIB, semua jenjang promosi, hak reviewer, revisi setoran, mint satu kali, batas bantuan, pergantian akun, validasi API dan daftar karyawan. Alur yang mengubah status kontrak diuji pada jaringan lokal. Pemeriksaan mainnet membaca status dan bytecode.

Di domain produksi, 12 permintaan untuk halaman, media, panduan dan API berhasil dengan HTTP 200. Pemeriksaan browser memakai ukuran 1.600 × 1.000 dan 390 × 844. Animasi WebM dapat dijeda dan diputar kembali. Dengan preferensi kurangi gerakan, browser menampilkan poster dan tidak memuat video saat masuk. Pada ponsel, papan Manager memuat lima tugas dan tombol Escape mengembalikan fokus ke tombol tugas setelah dialog ditutup.

Bytecode runtime hasil kompilasi dan kode kontrak di mainnet sama persis, sepanjang 17.008 byte. Keccak-256 keduanya `0xa8e982df9b10dfe6a8c36b9c75493d7ddf87d8a2aff25035b085c38d006a3bec`. [Kontrak ONERUB di BscScan](https://bscscan.com/address/0x7d7A4B8f27838aca993d6C2c086031301ee33A9C#code)

`npm audit --omit=dev` melaporkan nol advisori pada dependensi produksi. Pemeriksaan yang menyertakan dependensi pengembangan melaporkan satu advisori pada `Bytes.lastIndexOf` di OpenZeppelin 5.3.0. `Bytes.sol` tidak terdapat dalam daftar masukan kompilasi kontrak ONERUB. Versi pustaka dipertahankan untuk mereproduksi bytecode yang sudah diterbitkan. [Advisori OpenZeppelin](https://github.com/OpenZeppelin/openzeppelin-contracts/security/advisories/GHSA-9rcw-c2f9-2j55)
