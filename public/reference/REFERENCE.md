# Dayos design reference

Source: https://styles.refero.design/style/ee403055-480e-4bd4-9216-07c9ae2dde2e
Screenshot: dayos-reference.jpg (1600 × 1000). Source: https://images.refero.design/styles/refero.design/image/2017ab1b-5d33-4775-90c0-94083be69d85.jpg

Refero specifies SuisseIntlCond Bold uppercase at 130px, 0.90 line height and -0.03em tracking. SuisseIntl supplies body text. SuisseIntlMono supplies 12px labels. Content width is 1200px, section gaps 80px and card padding 24px. Page gray #e5e5e5, mint #d1ffca and yellow #fff100. Cards have 24–32px corners and navigation pills a 48px radius.

Current source font declaration: https://www.dayos.com/_nuxt/entry.BgyVURkz.css
Original font address: https://www.dayos.com/assets/fonts/SuisseIntlCond/SuisseIntlCond-Bold.otf
Local reusable fallback: BarlowCondensed-Bold.ttf from https://github.com/google/fonts/tree/main/ofl/barlowcondensed with the accompanying OFL license. Original Dayos font redistribution rights were not verified.

The live Dayos home page now uses a different hero. The screenshot documents the archived layout and 3D imagery.
